# Branchline 0.1.0

The first open-source release of Branchline, a native macOS app for browsing and syncing Git repositories.

- Browse a commit graph with branches and tags, search history, and inspect commit details and changed files.
- Organize multiple repositories and linked worktrees, with ahead and behind counts for each checkout.
- Fetch, fast-forward pull, stash and pull, or push selected repositories. Background fetch runs by default. Automatic fast-forward pulls for clean default branches are opt-in.

Open `Branchline-0.1.0.dmg` and drag Branchline to Applications. The universal installer is signed and notarized and requires macOS 14 or later.
